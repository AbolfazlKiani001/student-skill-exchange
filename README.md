# Student Skill Exchange

## معرفی پروژه
این پروژه یک سامانه تحت وب برای تبادل مهارت و یادگیری بین دانشجویان است. کاربران می‌توانند مهارت‌هایی را که بلد هستند ثبت کنند و افرادی را پیدا کنند که بتوانند مهارت‌های موردعلاقه‌شان را به آن‌ها آموزش دهند.

هدف این سامانه ایجاد بستری برای یادگیری متقابل بین دانشجویان و آسان‌تر کردن ارتباط افرادی است که مهارت‌ها و نیازهای آموزشی متفاوتی دارند.

## امکانات اصلی
- ثبت‌نام و ورود کاربران
- ایجاد و ویرایش پروفایل کاربری
- ثبت مهارت‌های قابل آموزش و مهارت‌های موردنیاز
- جست‌وجو و مشاهده مهارت‌ها
- پیدا کردن افراد مناسب برای یادگیری
- ارسال و مدیریت درخواست‌های آموزشی
- هماهنگی و زمان‌بندی جلسات
- ثبت نظر و امتیازدهی کاربران
- پنل مدیریت سامانه

## کاربران سامانه
- **دانشجویان:** برای یادگیری مهارت‌های جدید
- **آموزش‌دهندگان:** برای به اشتراک گذاشتن مهارت‌های خود
- **مدیر سامانه:** برای مدیریت کاربران و نظارت بر عملکرد سایت

## فناوری‌های مورد استفاده
- **بک‌اند:** Python و Django
- **پایگاه داده:** MySQL (با mysqlclient)
- **رابط کاربری:** HTML و کتابخانه mdui نسخه ۲ (طراحی Material Design 3)
- **فونت:** وزیرمتن

## اجرای پروژه
```
python -m venv venv
venv\Scripts\activate
pip install django mysqlclient
python manage.py migrate
python manage.py runserver
```

## توسعه‌های آینده
در نسخه‌های بعدی می‌توان قابلیت پیشنهاد هوشمند کاربران بر اساس مهارت‌ها و نیازهای آموزشی آن‌ها را به سامانه اضافه کرد.
